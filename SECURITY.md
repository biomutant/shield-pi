# Security Policy

Shield Pi is a community/hobby project and is not an audited security product. The NordVPN UI controls an installed NordVPN client; it does not replace NordVPN's cryptographic implementation.

## Reporting a vulnerability

Please do not publish credentials, tokens, private network details, or a working exploit in a public issue.

If GitHub private vulnerability reporting / security advisories are available for this repository, use that channel. Otherwise, open a minimal issue stating that you have a security concern and omit exploit details until a private contact channel is arranged.

## Scope

Security reports are especially useful for:

- command injection or unsafe shell invocation;
- privilege or permission problems;
- unsafe handling of remote input;
- unintended disclosure of local files, IP/network data, or logs;
- insecure temporary files or installers;
- VPN disconnect/quit behavior that could leave the user in an unexpected network state.

Please include the affected version and the minimum reproduction information needed to understand the issue.
